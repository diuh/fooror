# Модуль 2 — Конкурентний аналіз і ресьорч ринку

> **Артефакт:** FigJam-полотна — карта пошуку конкурентів + матриця «конкуренти × критерії» + полотно POD/POP. Заповнений приклад — переупакований research-дек UV.
> **Колір-тег:** 🟪 фіолетовий (зовнішній контекст).

---

## Ціль модуля

Навчити знаходити конкурентів, порівнювати їх за осмисленими критеріями, методом диференціації знаходити білі плями і формулювати **конкурентну перевагу** через POD і POP.

---

## Теорія

### Крок 1. Як знаходити конкурентів

Три типи — треба зібрати всі:

- **Прямі** — той самий продукт, та сама аудиторія (інші магазини в ніші UV).
- **Непрямі** — вирішують ту саму потребу інакше (маркетплейси, Instagram-магазини, офлайн).
- **Аспіраційні** — не конкуренти по ринку, але еталон по дизайну/досвіду (сильні бренди, на які хочемо рівнятись).

**Де шукати:**
- Google-пошук за запитами, якими шукає клієнт покупця («купити [товар] Україна»).
- Маркетплейси (Rozetka, Prom) — хто топить у категорії.
- Реклама (Google Ads, Meta Ad Library) — хто платить за трафік.
- Каталоги/агрегатори, тематичні спільноти, Instagram-хештеги.
- Питаємо клієнта: «на кого рівняєтесь / кого вважаєте конкурентом».

**Скільки:** 5–8 для глибокого розбору достатньо (3–5 прямих + 1–2 непрямих + 1–2 аспіраційних).

### Крок 2. Як визначити критерії аналізу

Критерії **не беруться зі стелі — вони виводяться з брифу (М1)**. Дивимось на цілі й функціонал проєкту і питаємо: «що з цього варто порівняти в конкурентів?».

Базовий набір критеріїв для e-commerce:

| Критерій | Що дивимось |
|----------|-------------|
| Функціонал | фільтри, кабінет, оплата, доставка, месенджери |
| UX-патерни | навігація, каталог, картка товару, кошик, чекаут |
| Візуальна мова | стиль, типографіка, фото, «характер» |
| Позиціювання | для кого, як себе подають |
| Пропозиція / ціна | ціни, акції, унікальні умови |
| Tone of voice | як говорять з клієнтом |
| Довіра | відгуки, гарантії, контакти |

### Крок 3. Метод диференціації

Будуємо **матрицю «конкуренти × критерії»**: рядки — конкуренти, стовпці — критерії, у клітинках — коротка оцінка/нотатка (можна зі скріншотом). Матриця одразу показує:
- **Патерни** — що є майже в усіх (це стане POP).
- **Білі плями** — те, що ніхто не робить добре (кандидати в POD).

Диференціація = шукаємо, де ринок однорідний і де можна виділитись.

### Крок 4. POD і POP → конкурентна перевага

- **POP (Points of Parity)** — «квиток на вхід». Те, що мусиш мати, щоб тебе взагалі сприймали серйозно (у e-commerce: зручний каталог, оплата карткою, доставка НП, месенджери). Відсутність POP = мінус, наявність — не перевага.
- **POD (Points of Difference)** — те, що вирізняє й дає причину обрати саме тебе. Має бути **важливим для аудиторії**, **відмінним від конкурентів** і **реальним для втілення**.

**Конкурентна перевага** = чітко сформульований 1–2 POD, підкріплені всіма POP.

> Формула: *«На відміну від [конкуренти], які [спільна риса/POP], ми [POD], що важливо для [аудиторія], бо [причина]».*

---

## Приклад UV: research-дек, переупакований у метод

У кейсі UV вже є посекційний розбір конкурентів зі скріншотами. Показуємо студенту, як ті самі матеріали лягають у метод:

1. **Список конкурентів** — прямі українські магазини ніші (ті, що в деку) + критерій, чому кожен потрапив у вибірку.
2. **Матриця** — конкуренти по рядках, критерії (функціонал, UX каталогу, візуал, довіра, tone of voice) по стовпцях; у клітинках — нотатки й скріншоти з дека.
3. **POP UV** — те, що мусить бути «як у всіх»: каталог із фільтрами, кабінет, оплата, доставка НП, месенджери (Viber/Telegram/Instagram — реальні патерни з дека).
4. **POD UV** — білі плями, де конкуренти слабкі (напр. подача бренду / якість візуалу / UX каталогу) → на цьому будуємо перевагу.
5. **Формулювання переваги UV** — за формулою вище.

> Порада для полотна: колонку «скріншот» у матриці роби клікабельною зоною — студент бачить доказ кожної оцінки, а не голослівний тег.

---

## Твій шаблон

**Полотно А — карта пошуку конкурентів:** три зони (Прямі / Непрямі / Аспіраційні) + чекліст джерел (пошук, маркетплейси, реклама, спільноти, питання клієнту). Під кожним конкурентом — «чому в вибірці».

**Полотно Б — матриця аналізу:** порожня таблиця конкуренти × критерії. Критерії студент добирає з брифу (є підказка-набір). Клітинки — під нотатку + скріншот.

**Полотно В — POD/POP:** дві зони-списки (POP «квиток на вхід» / POD «наша відмінність») + рамка з формулою конкурентної переваги для заповнення.

## AI-кроки

### AI-крок 1 — розширити список конкурентів і сегментів

**Промпт:**
```
Я досліджую ринок [ніша], регіон [країна]. Допоможи скласти список конкурентів:
окремо прямі, непрямі й аспіраційні. Для кожного — 1 рядок, чому він у цій групі.
Додай сегменти/ніші всередині ринку, які я міг проґавити.
Познач, що це гіпотези для перевірки, а не підтверджені дані.
```
**Приклад на UV:** AI пропонує групи магазинів + непрямі канали (Instagram-продажі, маркетплейси) як конкурентів за увагу.
**Застереження:** AI може вигадати неіснуючі бренди або застарілі дані — **кожного конкурента відкриваємо й перевіряємо руками**.

### AI-крок 2 — згенерувати критерії з брифу

**Промпт:**
```
Ось мій бриф: [бриф]. Запропонуй критерії для конкурентного аналізу цього проєкту,
згруповані (функціонал / UX / візуал / позиціювання / пропозиція / довіра).
Для кожного критерію — чому він важливий саме для цього проєкту.
```
**Застереження:** залишай критерії, що справді впливають на рішення; зайве — прибирай.

### AI-крок 3 — звести нотатки в матрицю

**Промпт:**
```
Ось мої нотатки по конкурентах: [нотатки]. Зведи їх у таблицю
конкуренти × критерії. Де даних немає — постав «—», не вигадуй.
Наприкінці познач: що є майже в усіх (кандидати в POP) і де є білі плями (кандидати в POD).
```
**Застереження:** POP/POD від AI — це **гіпотези**. Фінальне рішення про перевагу приймає дизайнер, звіряючись із аудиторією (М4).

### AI-крок 4 — проговорити перевагу

**Промпт:**
```
На основі цих POP і POD: [список] допоможи сформулювати 1–2 конкурентні переваги
за формулою: «На відміну від [конкуренти], які [POP], ми [POD], що важливо
для [аудиторія], бо [причина]». Дай 3 варіанти формулювання.
```
**Застереження:** обери й доопрацюй формулювання сам — воно має бути **реальним для втілення** вашою командою.

## Чеклист готовності модуля

- [ ] Зібрано 5–8 конкурентів трьох типів, у кожного — причина потрапляння у вибірку.
- [ ] Критерії аналізу виведені з брифу, а не взяті наосліп.
- [ ] Матриця заповнена з доказами (нотатки/скріншоти), а не на памʼять.
- [ ] Розділено POP (must-have) і POD (відмінність).
- [ ] Сформульовано конкурентну перевагу за формулою.
