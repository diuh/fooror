# Скіли курсу «Design Strategy»

Два скіли Claude Code, які покривають першу половину модуля 1 — розмову з клієнтом.
Вони працюють **у парі й по черзі**, як реальний процес: спершу знайомство, потім деталі.

```
small-talk-generator  →  brief-generator  →  (КП)
   «чи беремось»          «що саме робимо»
```

| Скіл | Що дає | Простий промпт студента |
|---|---|---|
| `small-talk-generator` | Сценарій першого дзвінка: 7–9 питань знайомства + перевірка метчу. Готові репліки під зачитування | `Small Talk для інтернет-магазину меблів` |
| `brief-generator` | Питання брифінгу по секціях Бізнес · Аудиторія · Конкуренти · Організаційне, до кожного — колонка «навіщо» | `бриф для інтернет-магазину меблів` |

## Головне: бриф памʼятає Small Talk

`brief-generator` перед генерацією перевіряє контекст і працює в одному з трьох режимів:

- **Small Talk є в цьому чаті** — теми з нього не повторюються. Замість них зверху зʼявляється блок «Уточнюємо після Small Talk»: те, що клієнт уже сказав, і що на брифі треба добрати цифрами.
- **Студент вставив нотатки з дзвінка** — скіл розбирає, що вже відомо, і питає тільки решту. Нічого не вигадує: чого клієнт не казав, лишається `[ПОТРІБНО УТОЧНИТИ]`.
- **Контексту немає** — повний бриф, де значком ⚡ помічені питання, які зазвичай уже закриті на Small Talk.

Тому найкращий сценарій для студента — **обидва скіли в одному чаті, підряд**:

```
1. Small Talk для лендингу стоматології
2. а тепер бриф під цей проєкт
```

Другий промпт достатньо простий саме тому, що весь контекст уже в розмові.

## Встановлення

Скіли лежать у `.claude/skills/` і підхоплюються автоматично, коли Claude Code запущено з кореня цього репозиторію.

Щоб користуватись ними в будь-якому проєкті — скопіюйте теки в свою домашню теку:

```bash
mkdir -p ~/.claude/skills
cp -r .claude/skills/small-talk-generator ~/.claude/skills/
cp -r .claude/skills/brief-generator ~/.claude/skills/
```

Перевірка: спитайте `які скіли доступні` або одразу напишіть `Small Talk для [ваш проєкт]`.
