TEMPORAL STIPPLE — як запустити
================================

ШВИДКО (без камери)
-------------------
Двічі клікніть index.html — відкриється у браузері.
Працює все: демо-зображення, свої картинки й відео (можна просто
перетягнути файл на полотно), усі повзунки.

Камера при такому запуску переважно НЕ працює: браузери не дають
доступ до камери сторінці, відкритій як file:// — це обмеження
браузера, а не скетчу.


З КАМЕРОЮ
---------
Потрібен Python 3 (на macOS і Linux уже є; на Windows —
python.org/downloads, при встановленні позначте "Add to PATH").

  macOS    двічі клікніть  start.command
  Windows  двічі клікніть  start-windows.bat
  Linux    у терміналі:    python3 start.py

Браузер відкриється сам на http://localhost:<порт>.
Далі: Camera → Start camera → дозвольте доступ.
Вікно терміналу не закривайте, поки користуєтесь. Ctrl+C — зупинити.

Якщо macOS каже, що файл із невідомого джерела: правий клік на
start.command → Open → Open.


ПОРАДИ
------
• Кількість крапок підбирайте під зображення. Якщо темний об'єкт
  малий, а фон світлий, 60 000 крапок нікуди не вміщаються і дають
  серпанок — зменште кількість або підніміть Contrast.
• Space — пауза, R — пересіяти крапки.
• Sample source color — крапки беруть колір із джерела.

Повний опис — у README.md.
